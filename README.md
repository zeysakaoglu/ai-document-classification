# AI Document Classification System

AI-powered system that classifies electronic documents into 5 departments:
Legal, Finance, Customer Services, R&D, Human Resources.

## Technologies
Python, NLP, LSTM, BERT, TF-IDF, Flutter, Flask

## Features
- Upload electronic document
- AI-based classification
- Percentage-based output
- Mobile-friendly interface

## Project Type
Graduation Project
